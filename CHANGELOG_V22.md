# V22 - Public school explorers with protected Administrator Preview

- BHS now opens directly at `https://app.palonious.com/`.
- GHS now opens directly at `https://app.palonious.com/ghs`.
- No-photo, school-specific career and course roadmaps do not require the demonstration code.
- Selecting Administrator Preview opens the access-code screen.
- Successful access returns the educator to the requested BHS or GHS preview.
- The protected preview still accepts only bundled fictional sample students.
- Real-student portrait mode remains disabled and unchanged.
- No DNS or Render environment-variable changes are required.
